# Дом рядом

**Дом рядом — помощь у порога.**

Прототип мини-приложения для жителей многоквартирных домов. Пользователь выбирает дом, указывает тип проблемы и получает информацию об ответственной службе и дальнейших действиях.

Проект разрабатывается для запуска в виде мини-приложения MAX.

## Что уже готово

- выбор дома из тестового списка;
- выбор категории проблемы;
- описание ситуации;
- проверка заполненных данных;
- определение управляющей или ответственной организации;
- подсказка о дальнейших действиях;
- копирование готового текста обращения;
- создание заявки;
- автоматический номер заявки вида `REQ-000001`;
- статус и время создания заявки;
- получение заявки по номеру;
- получение списка всех заявок;
- интерфейс для жителя;
- отдельная страница диспетчера;
- адаптивный дизайн для телефона;
- поддержка порта из переменной окружения `PORT`;
- подготовка к размещению на хостинге.

## Как работает приложение

1. Житель выбирает свой дом.
2. Выбирает категорию проблемы.
3. Описывает ситуацию.
4. Приложение определяет ответственную службу.
5. Житель может скопировать обращение или создать заявку.
6. Созданная заявка появляется в панели диспетчера.

- Go;

## Структура проекта

```text
dom-ryadom/
├── go.mod
├── main.go
├── buildings.go
├── routing.go
├── requests.go
└── web/
    ├── index.html
    └── admin.html
```

### Назначение файлов

- `main.go` — запуск сервера и HTTP-маршруты;
- `buildings.go` — тестовые дома и управляющие организации;
- `routing.go` — определение ответственной службы и следующего шага;
- `requests.go` — создание, хранение и поиск заявок;
- `web/index.html` — интерфейс жителя;
- `web/admin.html` — панель со списком заявок.

## Запуск проекта

Необходимо установить Go.

Клонируйте репозиторий:

```bash
git clone https://github.com/USERNAME/dom-ryadom.git
cd dom-ryadom
```

Запустите сервер:

```bash
go run .
```

После запуска откройте:

```text
http://127.0.0.1:8080/
```

Панель диспетчера:

```text
http://127.0.0.1:8080/admin
```

Проверка состояния сервера:

```text
http://127.0.0.1:8080/health
```

## API

| Метод | Адрес | Назначение |
|---|---|---|
| `GET` | `/health` | Проверка работы сервера |
| `GET` | `/categories` | Получение категорий проблем |
| `GET` | `/buildings` | Получение списка домов |
| `POST` | `/requests/preview` | Предварительная проверка обращения |
| `POST` | `/requests` | Создание заявки |
| `GET` | `/requests` | Получение всех заявок |
| `GET` | `/requests/{id}` | Получение заявки по номеру |
| `GET` | `/app` | Интерфейс жителя |
| `GET` | `/admin` | Панель диспетчера |

## Пример создания заявки

Запрос:

```json
{
  "category": "Протечка",
  "description": "Течёт труба в подъезде",
  "building_id": "house-1"
}
```

Пример ответа:

```json
{
  "id": "REQ-000001",
  "request": {
    "category": "Протечка",
    "address": "ул. Лесная, д. 5",
    "description": "Течёт труба в подъезде",
    "building_id": "house-1"
  },
  "managing_org": "Тестовая УК №1",
  "responsible": "Аварийно-диспетчерская служба",
  "next_step": "Свяжитесь с аварийно-диспетчерской службой вашего дома и сообщите адрес и место протечки.",
  "status": "Создана",
  "created_at": "2026-09-25T09:00:00+03:00"
}
```

## Текущее ограничение

Заявки временно хранятся в оперативной памяти сервера. После перезапуска:

- заявки удаляются;
- нумерация снова начинается с `REQ-000001`.

Панель диспетчера пока не защищена авторизацией.

Все дома и управляющие организации являются тестовыми.

